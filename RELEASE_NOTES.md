## 📱 How to Use New Features

### Using Country Flags
1. Open CrossSafe
2. Tap the screen or preset button
3. Select **"Country flags"** tab
4. Browse countries by region
5. Tap any country flag
6. Screen flashes in national colors!

### Switching Languages
1. Go to device Settings → System → Languages
2. Change to any supported language
3. Open CrossSafe
4. App automatically displays in that language!
5. No app settings needed
